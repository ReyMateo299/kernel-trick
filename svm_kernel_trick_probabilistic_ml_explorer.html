Probabilistic ML Insight

Kernels as Covariance Priors (RKHS ↔ GP)

In probabilistic machine learning, choosing a positive-definite kernel K(x, x') is equivalent to placing a Gaussian Process (GP) prior f ~ 𝒢𝒫(0, K) over the space of latent functions:

  • Prior Smoothness (γ): Controls how rapidly covariance decays with distance. Small γ enforces broad, smooth functions; large γ allows rapid local oscillations around each Support Vector.
  • MAP Estimation: The SVM objective minimizes regularized Hinge Loss C ∑ max(0, 1 - yᵢf(xᵢ)) + ½‖f‖²ℋ, which acts as a Maximum A Posteriori (MAP) estimate in Reproducing Kernel Hilbert Space (ℋK).
  • Epistemic Uncertainty: Via Platt scaling P(y=1|x) = 1/(1 + exp(-β f(x))), points near the hyperplane (f(x)=0) exhibit maximum predictive entropy (P=0.5, white band).
Mercer's Condition: K(x,x') = ⟨φ(x), φ(x')⟩ℋ ≥ 0 ✓ Valid PSD Covariance
